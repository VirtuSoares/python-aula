# 📌 Entregável de Desenvolvimento em Python – Semana 01 (Desafio Sprint 1)

Este repositório contém a resolução dos **6 mini-desafios da Prática Independente**, focados na consolidação dos conceitos fundamentais de Python: sintaxe, variáveis, tipos primitivos, operadores, entrada/saída de dados e manipulação de strings.

---

## 🎯 Objetivo da Atividade
A construção destes scripts visa fixar os fundamentos de programação em Python, aplicando na prática:
* Declaração e conversão de tipos de variáveis (`int`, `float`, `str`).
* Operações matemáticas e lógicas básicas.
* Captura e validação de dados de entrada (`input()`).
* Formatação de saídas usando *f-strings*.
* Boas práticas de código conforme a convenção **PEP 8** (`snake_case`).

---

## 🛠️ Desafios Implementados

1. **Calculadora de Troco:** Calcula o valor do troco a ser devolvido com base no valor total da compra e no valor pago.
2. **Média de Notas:** Recebe 3 notas, calcula a média aritmética e exibe o resultado formatado com 2 casas decimais.
3. **Conversor de Tempo:** Converte um valor total em segundos para o formato `Xh Ym Zs`.
4. **Calculadora de Desconto:** Aplica uma percentagem de desconto ao preço de um produto e exibe o valor final.
5. **Par ou Ímpar:** Identifica se um número inteiro é par ou ímpar utilizando o operador de módulo (`%`).
6. **Inversor de Nome:** Recebe uma cadeia de texto/nome e exibe o resultado invertido utilizando *slicing* (`[::-1]`).
